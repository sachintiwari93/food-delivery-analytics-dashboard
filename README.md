🍽️ Food Delivery Analytics Dashboard

📌 Project Overview

This project analyzes food delivery order data using SQL, Python, and Power BI. The dashboard provides business insights related to orders, revenue, customer ratings, restaurant performance, and delivery trends.

🎯 Objectives

* Analyze total orders
* Monitor revenue
* Track customer ratings
* Identify top-performing restaurants
* Analyze monthly and hourly trends
* Study delivery distance

🛠️ Tools & Technologies

* SQL
* Python
* Pandas
* Matplotlib
* Power BI
* Microsoft Excel

📊 Dashboard Features

* KPI Cards
* Orders by Status
* Revenue by Restaurant
* Orders by Month
* Orders by Hour
* Orders by Distance
* Date Range Slicer

📈 Key Insights

* Highest revenue generated by Aura Pizzas.
* Most orders were delivered successfully.
* Average customer rating is around 4.
* Peak order time is during evening hours.
* Most deliveries are within 1–3 km.
